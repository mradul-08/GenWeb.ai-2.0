quickcache

Lightweight JavaScript caching library for browsers and Node.js.

Getting Started

quickcache provides a simple API to store, retrieve and invalidate values in memory. It works both in the browser and in Node environments.

// Create a cache instance
const cache = quickcache({ ttl: 3000 }); // 3 seconds default TTL

// Store a value
cache.set('user:123', { name: 'Alice', age: 30 });

// Retrieve it later
const user = cache.get('user:123');
console.log(user); // { name: 'Alice', age: 30 }

Installation

Install via npm or use the CDN for quick experiments.

npm

npm install quickcache

CDN

<script src="https://cdn.jsdelivr.net/npm/quickcache@latest/dist/quickcache.min.js"></script>
<script>
  const cache = quickcache();
</script>

API Reference

quickcache(options?) → Cache

Creates a new cache instance.

quickcache({ ttl?: number, maxSize?: number })

Cache methods

  • set(key, value, ttl?) – Store value under key. Optional ttl (ms) overrides default.
  • get(key) – Retrieve the value or undefined if missing/expired.
  • has(key) – Returns true if a non‑expired entry exists.
  • delete(key) – Remove an entry.
  • clear() – Empty the cache.
  • size() – Current number of entries.

Example

// Custom TTL per entry
cache.set('session:abc', { token: 'xyz' }, 60000); // 1 min

if (cache.has('session:abc')) {
  const sess = cache.get('session:abc');
  console.log('session active', sess);
}

FAQ

Is quickcache safe for production?

Yes. It is pure JavaScript with no external dependencies. It uses a LRU eviction strategy when maxSize is set.

Can I use quickcache in a Service Worker?

Absolutely. The API works in any JavaScript context, including Service Workers and Node.

How does TTL work?

Each entry stores its expiration timestamp. On get the library checks the timestamp and automatically removes expired items.
