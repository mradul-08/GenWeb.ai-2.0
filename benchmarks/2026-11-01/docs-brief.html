Getting Started

QuickCache is a tiny, dependency‑free library that provides an in‑memory cache for JavaScript objects. It works in browsers and Node.js.

Include the script and you’re ready to cache data without any configuration.

Installation

Choose the method that fits your workflow.

Browser (CDN)

<script src="https://cdn.jsdelivr.net/npm/quickcache@1.0.0/dist/quickcache.min.js"></script>

Node.js / npm

npm install quickcache
const QuickCache = require('quickcache'); // CommonJS
// or
import QuickCache from 'quickcache'; // ES Modules

API Reference

new QuickCache([options])

Creates a cache instance.

const cache = new QuickCache({
  maxSize: 100,      // maximum number of entries
  ttl: 60000         // default time‑to‑live in ms
});

cache.set(key, value, [ttl])

Store a value. Returns the cache instance for chaining.

cache.set('user:1', {name:'Alice'}, 30000);

cache.get(key)

Retrieve a value. Returns undefined if missing or expired.

const user = cache.get('user:1');

cache.has(key)

Check existence without retrieving.

if (cache.has('user:1')) { … }

cache.delete(key)

Remove a specific entry.

cache.delete('user:1');

cache.clear()

Empty the entire cache.

cache.clear();

FAQ

Is QuickCache safe for concurrent access?
In a single‑threaded JavaScript environment (browser or Node.js) it is safe. For worker threads, create a separate instance per thread.
Can I persist the cache?
QuickCache is in‑memory only. Persisting requires serialising the data yourself (e.g., to localStorage or a file) and re‑hydrating a new cache instance.
What happens when the cache reaches maxSize?
The least‑recently‑used entry is evicted automatically.
