Getting Started

QuickCache is a tiny, dependency‑free JavaScript library that provides an in‑memory cache with TTL support. It works in browsers and Node.js.

Basic usage

import { cache } from 'quickcache';

// store a value for 5 seconds
cache.set('user:123', { name: 'Ada Lovelace' }, 5000);

// later...
const user = cache.get('user:123');
if (user) {
  console.log('Cache hit:', user);
} else {
  console.log('Cache miss');
}

Installation

QuickCache can be added to any project via npm, CDN, or as a plain script tag.

npm / Yarn

npm install quickcache
# or
yarn add quickcache

CDN

<script type="module" src="https://cdn.jsdelivr.net/npm/quickcache@latest/dist/quickcache.esm.js"></script>

Legacy script tag

<script src="https://cdn.jsdelivr.net/npm/quickcache@latest/dist/quickcache.umd.js"></script>
<script>
  const { cache } = QuickCache;
</script>

API Reference

All public methods are exposed via the cache object.

cache.set(key, value, ttl?)

Store value under key. Optional ttl (milliseconds) defines expiration.

cache.set('token', 'abc123', 60000); // expires in 1 min

cache.get(key)

Retrieve the value for key. Returns undefined if missing or expired.

const token = cache.get('token');

cache.has(key)

Return true if key exists and is not expired.

if (cache.has('token')) { … }

cache.delete(key)

Remove key from the cache.

cache.delete('token');

cache.clear()

Empty the entire cache.

cache.clear();

FAQ

Is QuickCache safe for server‑side rendering?

Yes. The library detects the environment and uses a simple object for storage in Node.js. No browser‑only APIs are required.

Can I store non‑JSON‑serializable values?

QuickCache stores values as‑is, so functions, class instances, or circular structures work as long as you keep them in the same runtime.

How does TTL work?

When a key is set with a TTL, the library records the expiration timestamp. On get or has it checks the timestamp and automatically removes expired entries.
